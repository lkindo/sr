# docs/archive — 수명이 끝난 문서 보관소

감사·정비 보고서는 **항목이 소진되면 여기로 옮긴다.** 소진되지 않은 문서를 옮기면
"끝난 것처럼 보이는 미결 항목"이 생겨서, 문서를 안 읽는 것보다 나쁘다.

## 왜 옮기는가

`docs/PROJECT_AUDIT_2026-07-29.md` 하나가 312KB 로 `docs/` 전체의 약 1/3 이다.
살아 있는 설계 문서(LLD/TRD/DB) 사이에 다 끝난 보고서가 같은 무게로 섞여 있으면,
새로 온 사람이 "지금 유효한 규칙"과 "그때 그랬던 기록"을 구분하지 못한다.

## 옮기는 조건

- 문서 안의 모든 항목이 **해소 / 수용된 위험 / 별도 티켓으로 이관** 중 하나로 종결되어야 한다.
- 옮길 때 문서 상단에 종결일과 "이 문서는 기록이며 현재 규칙이 아니다"를 한 줄 적는다.
- 문서를 가리키는 링크를 전부 갱신한다. 경로를 읽는 스크립트도 포함이다
  (`scripts/apply-audit-status.mjs` 가 감사 문서 경로를 상수로 들고 있다).
